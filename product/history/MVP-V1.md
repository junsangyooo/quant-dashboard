# MVP v1 (모의투자 전용 · 2026-10-29 ~ 31)

제품 주인이 자기 노트북에서 직접 써 보며 제품을 이해하려고 만든 설치형 앱이에요. 코드는 `../service/app/`에 그대로 있어요. **v2는 아직 코드가 아니에요** — 이 문서는 v1에서 한 것과 v2로 가며 바뀐 것을 요약해요.

## 1. 한눈에

| 항목 | v1 |
|---|---|
| 하는 일 | 비밀번호 · 복구 코드 로그인, 토스 API 키 연결 확인(조회만), 캔버스 전략 편집, 백테스트, 모의투자(평일 16:30 자동 확인 · 다음 거래일 시가 모의 체결) |
| 하지 않는 일 | 실전 주문 · 정정 · 취소 · 조건주문(코드에 없음 · 시험으로 확인). 토스에는 조회만, POST는 토큰 받기 한 번 |
| 데이터 | 일봉은 야후 금융(`.KS` / `.KQ`), 코스피 비교 `^KS11`. 토스가 연결돼 있으면 보유 평가에 토스 현재가 |
| 전략 | 캔버스에 조건(15개 · ① 유니버스 ~ ⑦ 비중)을 놓고 선으로 이어요. 한 경로 위는 모두 맞아야 하고 경로끼리는 하나라도. 매매 방식은 놓은 조건으로 정해져요. 예시 전략 4개(보기 전용) |
| 화면 | 운영 사이트(`web/`)의 부품 · 토큰 · 글꼴을 가져와 새로 만든 React 화면. Figma MVP 화면 98장 기준 |
| 접속 | 127.0.0.1:8765만. 다른 기기에서는 안 열려요 |
| 키 보관 | 무작위 데이터 키로 비밀 값을 AES-GCM으로 잠그고, 데이터 키를 비밀번호(scrypt) · 복구 코드로 감싸요. 로그인한 동안만 메모리에(세션 12시간). 잠그면 키 · 토스 연결 객체 · 토큰을 버려요 |
| 비용 계산 | 수수료 0.015%(사고팔 때) · 매도 세금 0.18%. 평균 단가에 매수 수수료 포함 |

## 2. 경과

| 날짜 | 한 일 |
|---|---|
| 2026-10-29 | 첫 MVP를 반려하고 **디자인부터 다시**(Figma 화면 근거 · 문구 검토). 용어 조사(칸 → 단계 · 조각 → 조건 · 판단 → 확인 등). MVP 디자인 검토 지적(M1~M9 · m1~m16) 처리. 앱을 만들고 검토 세 번(첫 체결 날짜 규칙 · 조사 고르기 · 일봉 없는 종목 코드 · 차트 축 · 잠그기 = 앱 전체 잠금 · 세션 만료 때 토큰 버리기 · 기간 글 한 함수 등) |
| 2026-10-30 | 제품 주인이 **자유 캔버스**를 고름. 캔버스 의미 규칙(경로 · 잇기 · 매매 방식 · 저장 형식 `quant-strategy/2`) 확정, 캔버스 디자인 검토 처리, 화면 페이지 마지막 검토 처리(흐름 다섯 · 1440 그림 · 새 전략 저장 흐름) |
| 2026-10-31 | 캔버스 MVP 검토 지적 처리(숫자 칸 값 동기화 · 선 우회 · 경로 수 막힘 문구 · 키보드 잇기 등) |

## 4. v2로 바뀐 것

| 영역 | v1 | v2 (`../service/SPEC.md`) |
|---|---|---|
| 목적 | 모의투자 전용 · 노트북 | **실전 운용이 메인** · 고객 서버나 늘 켜 둔 PC · 모의투자는 별도 탭 |
| 접속 | 127.0.0.1만 | 127.0.0.1 + Tailscale 사설망 · 390 휴대폰 화면 |
| 키 | 로그인한 동안만 메모리 | 컴퓨터 키 파일로 감싸 재부팅 뒤 로그인 없이 운용 · 돈이 움직이는 일은 비밀번호 다시 |
| 데이터 | 야후 일봉 · DART 없음 | 토스 일봉 · 수급 · 섹터 · 지수 + 고객 DART(선택) |
| 확인 시각 | 평일 16:30 | 평일 20:10 확인 → 다음 거래일 08:30 점검 → 08:35 시가 단일가 주문 |
| 편집기 | 노드 = 조건 하나(15개) | 노드 = 단계 블록 + 조건 줄(카탈로그 약 50개) + '모두 / 하나라도' · 문장으로 보기 |
| 매도 | 종가로 확인 → 다음 날 시가 | 실행 방식 셋(장중 감시 · 조건주문(토스) · 종가 확인) · 보호 매도 하한 없음 |
| 돈 규칙 | — | 매도 대금은 다음 거래일 매수부터 · 수량 = 목표 ÷ 지정가 상한 · 한도 3줄 + 고정 2줄 |
| 알림 | 없음 | 고객 텔레그램 봇 + 알림함 · 08:30 점검 메시지 |
| 예시 전략 | 4개(보기 전용) | 없음(투자 권유로 읽힐 수 있어요) |
| 복사 글 | `quant-strategy/2`(그래프) | `quant-strategy/3`(블록) · v1 · v2 글은 읽을 때 변환 |
| 문구 | '이 앱은 실전 주문을 내지 않아요' · '모의투자' 머리 칩 | 모두 없앰(SPEC 8-1) |
