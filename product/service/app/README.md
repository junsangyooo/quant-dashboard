# quant 실전 운용 앱 (v2)

내 컴퓨터(서버 또는 늘 켜 둔 PC)에서 돌며 내 토스증권 계좌로 전략을 실전 운용하는 앱이에요. 기획은 `../SPEC.md`, 엔진 규칙은 `../ENGINE-RULES.md`, 개발 순서와 결과는 `../TASKS.md`, 개발 규칙은 `../../DEVELOPING.md`예요.

- 전략은 단계 블록(① 유니버스 ~ ⑦ 비중)을 이어 만들고, 이 앱에서 백테스트한 버전만 모의투자 · 실전 운용해요.
- 화면은 127.0.0.1과 내 Tailscale에 추가한 기기에서만 열려요. 공개 인터넷에는 열지 않아요.
- **전송은 기본 가짜예요.** 토스 주문 · 텔레그램 · DART · 공인 IP는 설치기가 `--live`로 쓰는 설정 파일과 환경 변수 `QUANT_LIVE_TRANSPORT=1`이 **둘 다** 있을 때만 밖으로 나가요(`app/transport.py`). 개발 · 시험 · `./start.sh`는 늘 가짜예요.

## 켜기 · 끄기

```bash
cd product/service/app
./start.sh   # 켜기(처음이면 파이썬 · 화면 빌드). python -m app.serve: 127.0.0.1에만 묶고 같은 데이터 폴더로 두 번 켜지 않아요
./stop.sh    # 끄기
```

- 주소: http://127.0.0.1:8765
- 서버 · PC에 서비스로 설치하는 법(재부팅 뒤 자동 시작 · Tailscale · 업데이트 · 지우기)은 `../INSTALL.md`.

## 처음 쓸 때(마법사 7단계)

1 비밀번호 만들기 → 2 복구 코드 → 3 설치 위치(서버 / 늘 켜 둔 PC) → 4 Tailscale → 5 토스 연결 → 6 텔레그램(실전 운용에 필요) → 7 DART(선택). 그다음 전략 › 새 전략 → 백테스트 → 모의투자 또는 실전 운용 시작(비밀번호).

## 키 · 비밀번호

- 데이터 키 하나로 API 키를 AES-GCM으로 잠그고, 데이터 키는 비밀번호 · 복구 코드 · **컴퓨터 키 파일**(`~/.config/quant-service/keyfile` · 600 · 레포와 데이터 폴더 밖) 셋으로 감싸요. 재부팅 뒤에는 키 파일로 풀어 **로그인 없이 운용이 이어지고**, 화면은 비밀번호로 열어요.
- 돈이 움직이는 일 · 키 바꾸기 · 삭제 · 복원 · 앱 데이터 삭제(SPEC 7-4)는 비밀번호를 한 번 더 받아 짧은 1회용 토큰을 써요. 새 매수 멈춤(텔레그램 `/멈춤` 포함)은 로그인만.
- 바꾸는 요청은 CSRF 값 · SameSite=Strict 쿠키 · Host · Origin 검사(127.0.0.1 · 등록한 ts.net 이름)를 거쳐요.

## 데이터

데이터 폴더(기본 `data/`, 서비스는 `/var/lib/quant-service/data`)의 `app.db`(sqlite · 600). 설정 › 데이터에서 백업 파일 받기(API 키 제외) · 복원(새 매수 멈춤으로 시작) · 기록 CSV · 앱 데이터 삭제(운용 중이면 막힘).

## 개발

```bash
.venv/bin/python -m pytest -p no:warnings -o addopts="--basetemp=tests/.tmp -p no:cacheprovider" -q
cd web && npm run typecheck && npm run lint && npm test && npm run build
```

- 시험은 바깥 네트워크 시도를 모두 세어 0이 아니면 실패해요. 토스는 `tests/fake_toss.py`(OpenAPI 1.2.28 꼴 검사), 텔레그램은 `tests/fake_telegram.py`.
- 그림 비교: `tests.e2e_server <폴더> 8799 [live]`를 켜고 `node web/e2e/compare.mjs http://127.0.0.1:8799 <출력> <editor|strategies|backtest|paper|settings|live> <번호>` → `../design/compare/`.
