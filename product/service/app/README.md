# 자동매매 MVP (모의투자 전용)

MVP v1(모의투자 전용) 코드예요. v2(실전 운용 · 단계 블록 편집기)는 `../SPEC.md`와 `../TASKS.md`를 따라 이 코드를 넓혀 만들어요.

- 비밀번호로 앱을 열고, 토스 API 키는 화면에서 입력해요. `.env` 파일은 만지지 않아요.
- 전략은 캔버스에 조건을 놓고 선으로 이어 만들어요(조건 15개 · 단계 ① 유니버스 ~ ⑦ 비중). 선을 따라 한 경로 위의 조건은 모두 맞아야 하고, 경로끼리는 하나라도 통과하면 돼요. 매매 방식은 놓은 조건으로 정해져요.
- 화면은 운영 사이트(quant-dashboard/web)의 부품 · 토큰 · 글꼴을 그대로 가져와 `web/`에 새로 만들었어요(Figma MVP 화면 98장 기준).
- 백테스트와 모의투자만 돼요. **이 앱은 실전 주문을 내지 않아요.**

## 켜기 · 끄기

```bash
cd product/service/app
./start.sh   # 켜기. 처음이면 준비(파이썬 · 화면 빌드, 1~3분) 뒤 브라우저가 열려요. 이미 켜져 있으면 열기만 해요
./stop.sh    # 끄기
```

- 주소: http://127.0.0.1:8765 (이 컴퓨터에서만 열려요)
- 필요한 것: Homebrew Python 3.12 (`/opt/homebrew/bin/python3.12`), Node.js 24(처음 화면을 빌드할 때만)
- 화면은 `web/dist`(빌드 결과)를 서버가 `/`에서 내줘요. 이미 빌드돼 있으면 start.sh는 빌드를 건너뛰어요. 화면을 고친 뒤에는 `cd web && npm run build`
- 끄거나 다시 켜면 앱이 잠겨요. 비밀번호를 넣으면 다시 돌아요.

## 처음 쓸 때

1. `./start.sh`로 켜요.
2. **처음 열기 · 비밀번호 만들기**: 비밀번호(8자 이상)를 두 번 입력하고, '만 19세 이상이에요'와 사용 조건에 체크해요.
3. **복구 코드 16자**가 한 번만 보여요. 적어 두세요. 비밀번호를 잊으면 로그인 화면의 '비밀번호를 잊었어요'에서 이 코드로 새 비밀번호를 만들어요(쓴 코드는 버리고 새 코드를 줘요). 비밀번호를 알고 있으면 설정 › 비밀번호 변경에서 바꿔요.
4. (선택) **설정 › 연결**에서 토스 API 키를 입력하고 '연결 확인'을 눌러요.
5. **전략 › 새 전략**에서 빈 캔버스 · 예시에서 시작 · 복사한 전략 붙여 넣기(`samples/`의 견본 글) 중 하나를 골라요. 예시 전략 4개는 앱 안에 있고 보기만 해요(바로 백테스트할 수 있어요).
6. 캔버스 편집(창 폭 1024 이상)에서 조건을 끌어 놓고 연결점을 끌어 잇고, 숫자를 입력해 저장해요. 새 전략은 처음 저장할 때 버전 1이 돼요. 빈칸은 단위와 허용 범위만 보여요(제품 기본값 없음).
7. **백테스트**로 과거를 돌려 보고, **모의투자 시작**을 눌러요.

## 토스 API 키 등록하는 법

1. 토스증권 PC(WTS)에서 Open API를 신청해요.
2. 키 받기에서 Client ID와 Client Secret을 받아요.
3. **허용 IP**에 이 컴퓨터의 공인 IP를 등록해요. 와이파이(집 · 회사 · 카페)가 바뀌면 공인 IP도 바뀌니 다시 등록해야 해요. 앱의 '이 컴퓨터 공인 IP 보기'를 누르면 공개 서비스(api.ipify.org)에 한 번 물어봐요(누를 때만).
4. 앱의 설정 › 연결 › 토스증권 Open API에 입력하고 저장 → '연결 확인'.

연결 확인은 **조회만** 해요: 액세스 토큰 받기 → 계좌 → 삼성전자 현재가. 결과는 '연결됐어요 · 10/29(목) 14:32 확인'과 삼성전자 현재가로 보여요. 계좌번호를 넣었으면 계좌 끝 4자리도 보여요.
실패하면 원인 한 줄과 다음 행동이 나와요(API 키가 맞지 않아요 / 허용 IP에 이 컴퓨터가 없어요 / 토스가 응답하지 않아요).

> **같은 키를 다른 프로그램(예: 서버의 운영 앱)과 같이 쓰지 마세요.** 토스는 키 하나에 토큰 하나만 살려 둬서, 여기서 연결 확인을 하면 그쪽 토큰이 끊겨요. 이 앱 전용 키를 따로 받는 게 좋아요.

토스가 연결돼 있으면 모의투자 보유 평가에 토스 현재가를 쓰고, 아니면 야후 금융 마지막 종가를 써요.
DART 칸은 화면에서 뺐어요(서버의 저장 주소만 남아 있어요).

## 키는 어떻게 보관되나

- 무작위 데이터 키 하나로 비밀 값들을 AES-GCM으로 잠가요.
- 데이터 키는 비밀번호에서 scrypt로 만든 키로 한 번, 복구 코드에서 만든 키로 한 번 감싸 둬요.
- 로그인한 동안만 풀린 데이터 키가 서버 메모리에 있어요(세션 12시간). 설정 › 잠그기를 누르거나 앱을 끄면 모든 세션이 끝나고 키가 메모리에서 사라져요(자동 확인은 키 없이 계속 돌아요).
- 비밀 값은 화면 · 응답 · 로그에 나오지 않아요. Client ID · Client Secret은 끝 4자리만 보여요(계좌번호는 넣었을 때만 끝 4자리).
- 비밀번호 5번 틀리면 5분 잠겨요(복구 코드 틀림도 같이 세요).

## 데이터는 어디에

모두 `mvp/data/` 안에 있어요.

| 파일 | 내용 |
|---|---|
| `data/app.db` (+ `-wal`, `-shm`) | 계정 정보, 잠긴 API 키, 전략과 버전, 받아 둔 일봉, 모의투자 기록 |
| `data/server.log` | 서버 접속 기록(주소와 상태 코드만 · 야후 라이브러리 경고는 쓰지 않아요) |
| `data/yfinance-cache/` | 야후 금융 캐시 |
| `data/server.pid` | 켜진 서버 번호 |

## 지우는 법

```bash
./stop.sh
rm -rf data          # 계정 · API 키 · 전략 · 기록이 모두 삭제돼요. 다음에 켜면 '처음 열기'부터예요
rm -rf .venv web/node_modules web/dist   # 설치한 패키지와 빌드한 화면까지 지우려면
```

앱 폴더(`mvp/`)를 통째로 삭제해도 돼요. 토스 쪽 키는 토스증권 WTS에서 삭제해요.

## 이 앱이 하지 않는 것

- **실전 주문 없음.** 주문 · 정정 · 취소 · 조건주문 기능이 코드에 없어요. 실전 모드도 없어요.
- 토스에는 조회(GET)만 보내요. POST는 토큰 받기 한 번뿐이에요.
- 서버는 127.0.0.1에만 묶여 있어요. 다른 기기(휴대폰 등)에서는 열리지 않아요.
- 투자 조언을 하지 않아요. 투자 판단과 손익은 본인 몫이에요.

## 규칙 요약

- 확인은 그날 **종가**, 체결은 **다음 거래일 시가**예요. 손절 · 익절도 종가로 확인해요(장중 가격은 보지 않아요).
- 비용: 수수료 0.015%(사고팔 때), 매도 세금 0.18%.
- 일봉은 야후 금융(`.KS`, 없으면 `.KQ`), 코스피 비교는 `^KS11`. 받은 일봉은 `app.db`에 담아 둬요.
- 모의투자 확인은 '지금 신호 확인' 단추, 또는 앱이 켜져 있으면 평일 16:30에 자동으로 한 번 실행돼요(로그인하지 않아도). 앱이 꺼져 있던 날은 다음 확인 때 하루씩 이어서 채워요. 오늘 일봉은 15:50 뒤에만 써요.

## 개발용

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest        # 네트워크 없이 실행돼요(가짜 토스 · 가짜 일봉 · 가짜 공인 IP)
cd web && npm run typecheck && npm run lint && npm test && npm run build
MVP_TOSS_OFFLINE=1 ./start.sh     # 토스 · 공인 IP 서비스에 나가지 않고 켜기(연결 확인은 '응답 없음'으로 끝나요)
```
