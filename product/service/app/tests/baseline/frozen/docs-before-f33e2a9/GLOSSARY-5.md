## 5. 금지어 (화면 글 · 빌드 결과에서 0건)

| 금지어 | 예외(허용하는 꼴) |
|---|---|
| 고쳐 · 고칠 · 지워 · 지웠 · 넣어요 · 넣은 값 | — |
| 넣기 | '붙여 넣기' |
| 돌아요 · 한 줄 · 갈래 · 노드 · 템플릿 · 끄는 중 · 까닭 · 전략 코드 · 저절로 | — |
| 포트 | '리포트' · '서포트' |
| (가져옴) · (내 전략) · 거르기 · 배정 · 블록 | — |
| 시험 | '시험 보내기'(텔레그램 단추) |
| 테스트 | '백테스트' |
| 전략 바꾸기 | — |
| 칸 | '빈칸' · '숫자 칸' · '입력 칸' |
| 조각 · 실행기 · 증권사에 걸 | — |
| 판단 | '투자 판단' |
| 내 서버 · 내 앱 열기 · 사용권 · 설치 없이 체험 (lab) | — |
| 칩 글자가 정확히 '예시' 또는 머리 칩 '모의투자' | 모의투자 탭 이름 · 제목 '모의투자'는 허용 |
| '이 앱은 실전 주문을 내지 않아요' · '숫자를 채워 둔' | — |
| SPEC 8-1 '없앨 MVP 문구' 표의 왼쪽 열 전부 | — |
| 내부 낱말: 우리 수량 · 장부 · clientOrderId · OPG | 코드 · 로그 안은 괜찮아요(화면 글만) |

검사 꼴(예):

```bash
# web/src 화면 글 + 빌드 결과에서 금지어 찾기 (예외 꼴을 지운 뒤 남은 것만 센다)
grep -rnoE '고쳐|고칠|지워|지웠|넣어요|넣은 값|돌아요|한 줄|갈래|노드|템플릿|끄는 중|까닭|전략 코드|저절로|거르기|배정|블록|전략 바꾸기|조각|실행기|증권사에 걸' web/src/copy web/src/copy.ts web/dist
```

- 기존 시험 `tests/test_copytext.py`(서버 글)와 `web/tests/words.test.ts` · `web/tests/oldWords.ts`(화면 글)를 이 목록으로 늘려요(SPEC 11-2 '문구').
