# 낱말 규칙 (화면 글 · v2)

화면에 나오는 글(단추 · 칩 · 알림 · 오류 · 텔레그램 · 서버가 돌려주는 오류 글)을 쓸 때 따르는 규칙이에요.

- 정답 순서: 그림 · `SPEC.md`에 글자가 있으면 **그 글자 그대로** 써요. 없는 글만 이 문서 규칙으로 지어요.
- 근거: v1 용어 조사(2026-10-29, 토스 명세 · 키움 · 미래에셋 · 퀀터스 · 젠포트 · 인텔리퀀트 · 운영 사이트 `web/src/copy.ts`), SPEC 8절, 디자인 검토 뒤 낱말 결정(2026-11-01). v1 조사와 v2 SPEC이 다른 곳은 v2를 따랐고, 표에 '(v2)'로 적었어요.
- 개발 검사: 화면 글과 빌드 결과(`web/dist`)에서 5절 금지어 0건(DEVELOPING 6). SPEC · 그림의 화면 글에는 금지어가 없어요(2026-11-02 SPEC 문구를 그림에 맞춰 고침). 그래서 '글자 그대로'와 '금지어 0'은 부딪히지 않아요. 부딪히는 곳을 찾으면 `OPEN-QUESTIONS.md`에 적어요.

## 1. 말투

| 규칙 | 예 |
|---|---|
| '~요'로 써요. '~해 주세요'보다 '~해요' | '매도 단계는 매수 단계 뒤에 이어요' |
| 국내 투자 앱이 쓰는 낱말만 써요. 지어낸 순우리말은 쓰지 않아요 | '필터'(○) · '거르기'(✕) |
| 날짜는 '11/3(화)', 시각은 24시간제 | '11/2(월) 20:10 확인 · 11/3(화) 08:35 주문' |
| 금액에는 단위. 최대와 예상을 나눠 보여요 | '매수 최대 9,980,000원 · 예상 9,100,000원' |
| 값과 단위는 한 덩어리(줄바꿈 금지) | '−7%' · '50억 원' |
| 한 줄 안의 묶음은 ' · '로 이어요 | '연결됐어요 · 주문할 수 있어요' |
| 버튼 · 이름 낱말은 한자어(변경 · 삭제 · 입력 · 수정), 문장 속 동사는 자연스러운 말('바꾸면 · 바뀐') | 단추 '전략 변경' · 문장 '바꾼 값은 다음 20:10 확인부터 적용해요' |
| '버전 n' 같은 숫자 뒤 조사는 받침에 맞춰 골라요 | '버전 1로' · '버전 3으로' · '버전 10으로' |
| 하나 고르기는 라디오, 동의 체크는 기본 빈칸 | — |
| 화면에 '시험'을 쓰지 않아요(텔레그램 단추 '시험 보내기'만 예외) | 연결 확인 결과는 '메시지 받음' |
| 내부 낱말은 화면에 0건: 우리 수량 · 장부 · clientOrderId · OPG · 보호 매도 길 · 블록 | — |
