# lab(실험실) 기획 (v2와 맞춤 · 2026-11-01 · UX 평가 반영 2026-11-02)

lab은 누구나 전략을 실험해 보는 **공개 웹사이트**예요. 사용자(운영자)가 배포하고, quant 서비스(설치형 앱)와는 **전략 복사 글 하나**로만 이어져요. 이 문서는 v2 앞의 기획 기록(r25판)의 lab 항목을 그대로 옮기고, quant 서비스 v2(`../service/SPEC.md` 9절)와 맞춘 것을 더한 거예요.

- 그림: [design/FIGMA.md](design/FIGMA.md) (Figma 'lab' 페이지 · 화면 9개 · 프레임 11장 + 목차 = 12장)
- UX 평가 반영(2026-11-02): 처음 쓰는 사람 기준 독립 검토의 지적으로 그림을 고쳤어요. 바뀐 것은 6절이고, 2 · 4절 표도 그에 맞췄어요.
- 정답의 순서: 앱과 겹치는 규칙(복사 글 형식 · 계산 규칙 · 낱말)은 `../service/SPEC.md`가 이겨요. lab에만 있는 것은 이 문서가 정답이에요.
- 상태: **기획 · 그림만 있어요.** lab 코드는 이 폴더에 없어요. 지금 운영 사이트의 `web/` 안 '전략 검증'(quant.jsyoo.dev/lab) 화면이 옛 실험실이고, 이 기획은 그것을 공개 사이트로 다시 만드는 안이에요.

## 1. 한눈에

| 질문 | 답 |
|---|---|
| 무엇 | 운영자가 구한 과거 자료로 전략을 대량으로 돌려 본 결과를 공개하는 실험실. 발굴 로직(①~④) × 매매 로직(⑤~⑦) = 전략 |
| 누가 · 어디에 | 사용자(운영자)가 배포하는 공개 사이트. 누구나 무료로 봐요(결정 2026-10-28 · 2026-11-01) |
| 하는 일 | 블록 편집, 백테스트, 등록한 전략 매일 추적(주문 없는 모의), 검증 내역 공개, 비교, 전략 복사 글 만들기 |
| 하지 않는 것 | 앱에 접속하지 않아요. 키 · 계좌 · 결과를 받지 않아요. 앱 주소를 묻지도 저장하지도 않아요. 설치 없는 체험 · 사이트 안 백테스트 대행 · 운영형은 없어요 |
| 앱과 주고받는 것 | lab → 앱: 전략 복사 글(`quant-strategy/3`, 숫자 · 종목 · 섹터 비움)만. 규격(항목 id 사전 · 코드 · 검사 값 · 예시)은 `../service/ENGINE-RULES.md` 11절이고, lab도 그대로 따라요. 앱 → lab: 그냥 링크 '실험실 열기 ↗' 하나 |
| 함께 쓰는 규격(문서로만) | 조건 카탈로그(`../service/DATA-CATALOG.md` 1절) · 항목 id 사전과 블록 연결 규칙 · 계산 규칙(`../service/ENGINE-RULES.md`) · 낱말(`../service/GLOSSARY.md`) |
| 결과가 같나 | 아니오. lab은 상장폐지 종목을 포함한 운영자 자료, 앱은 고객의 토스 · DART 자료(상장폐지 없음)라서 달라요. 화면에 이 차이를 늘 보여요 |
| 돈 | 앱 판매와 상관없어요. 운영자가 갱신을 멈춰도 산 사람의 앱과 이미 가져간 전략은 그대로 돌아요(DEC-LAB-KEEP) |

## 6. UX 평가 반영 (2026-11-02)

처음 쓰는 사람 기준 독립 검토의 lab 판정은 '아니오'였어요(첫 화면 목적이 안 보이고, 상위 전략 대부분이 '앱에서는 못 써요'이고, 가져가는 법이 모호). 그림을 두 번 고쳤어요(1차 U-80 ~ 85 · 전후 비교 검토 뒤 2차 R2-40 ~ 47). 특정 전략을 권하지 않는다는 원칙(DEC-NO-ADVICE)은 그대로예요.
