# 계약 공백 — 아직 열린 것

2026-10-09 API 세션이 정리했다. 화면 에이전트가 찾은 공백은 CONTRACT.md에 반영했다(맨 아래 '바뀐 것'의 2026-10-09 줄들). 헤더가 AI 규칙 자료를 세는 일과 AI 판단 요약의 서버 문구도 같은 날 닫았다. 여기에는 아직 정하지 못한 것과 API 밖에서 정할 것만 남긴다.

## 정할 것(API)
1. **실적 발표일 예정 항목(`ScheduleItem.earnings`)**: 계약에 자리만 있고 보내지 않는다. 발표일을 미리 알려 주는 공개 자료원이 없다(DART·EDGAR는 공시가 나온 뒤에만 안다).

## API 밖(웹·디자인·유준상)
2. AI 판단 카드는 Figma 그림이 없다. 웹이 노드 카드 말투로 만들었다(칸 이름 '판단').
3. 디자인 시스템: Figma `flow/*` 변수 4개가 tokens.json에 없다(페이지 CSS에서 기존 토큰으로 매핑). 390 프레임의 옆 여백 16과 앱의 20이 다르다.
4. 예시 값표에 없는 숫자로 만든 고정 자료가 있다(7/1 주문가, 9/14 비중, 9/30 비중, 실전 수수료·월 변동, 끈 기간 9/21~9/25, 10/4 주말, AI 판단 10/2, 3년 발굴 흐름 값). 웹 세션의 예시 값표에 더할지 정한다.
5. 새로 지은 문구는 `web/src/copy/{pin,health,mode,account}.ts`에 NEW로 표시돼 있다. 유준상에게 한 번 보여 준다. 이번에 웹이 새로 지을 말(지표 이름 17개, 남은 값의 단위, 판단 카드 항목)도 같이 보여 준다.
